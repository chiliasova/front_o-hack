# О!дин запрос — фронтенд

AI-агент для путешествий (О! Хакатон, Островок 2026). Split view: слева чат с агентом, справа «холст поездки».

**Стек:** React 18 + TypeScript + Vite, без UI-библиотек (чистый CSS). QR-код ваучера — `qrcode.react`.

## Запуск

```bash
# локально (http://localhost:8080), /api проксируется на http://localhost:8000
npm install
npm run dev

# в Docker (nginx на 8080, /api и /health проксируются на http://backend:8000)
docker compose -f docker-compose.frontend.yml up --build
```

Для общего `docker-compose.yml` в корне репозитория достаточно скопировать сервис `frontend`
из `docker-compose.frontend.yml` (поменять `context: .` на `context: ./frontend`).

## Работа без бэкенда

API-клиент (`src/api/client.ts`) работает в трёх режимах, задаётся `VITE_API_MODE` при сборке:

| режим | что делает |
|---|---|
| `auto` (по умолчанию) | ходит в бэкенд; если он не отвечает (сеть, 404, 5xx, не JSON) — отвечают моки, в хедере появляется бейдж «демо-данные» |
| `mock` | только моки — демо работает вообще без сервера |
| `live` | только бэкенд, ошибки показываются пользователю |

Моки (`src/api/mock.ts`, `src/api/mockData.ts`) повторяют ответы из FRONTEND_API_SPEC.md и сохраняют
бронирования/баллы в localStorage. Сбросить: `localStorage.removeItem('odin-mock-store-v1')`.

### Демо-сценарии для жюри

- **Алексей (семья + собака)**: «В Сочи на выходные» → отель помечен «Можно с питомцем», в «Почему подходит» упомянут корги.
  «Найди дешевле» → другой отель, даты сохраняются. «Куда поехать с собакой на майские?» → Карелия, pet-friendly.
- **Елена (Премиум + Шенген)**: «Рим на 4 дня, хочу красиво» → бутик-отель 5★ в Риме.
  Тот же запрос от Гостя или Алексея → агент объясняет, что нет шенгенской визы, и предлагает альтернативу.
- **Гость**: «Питер до 40 000 ₽» → жёлтый бейдж: поезд приходит в 09:40, заселение в 14:00 (агент ловит проблему стыковки).
- **Горящие туры** → «Собрать тур» → холст с горящей ценой.
- **Оформление**: баллы «Банка снов», промокод `OSTROVOK` (−5%), оплата → ваучер `OST-XXXXXX` с QR → «Мои поездки»:
  ранний заезд, смена дат, трансфер, вопрос отельеру.

## Какие ручки использует фронт

| ручка | где |
|---|---|
| `POST /api/chat` | чат, холст поездки |
| `GET /api/deals/hot` | вкладка «Горящие туры» |
| `GET /api/user/profile` (заголовок `X-User-ID` + `?user_id=`) | хедер, баллы, приветствие, чекаут |
| `POST /api/trips/{id}/book` | чекаут → ваучер |
| `POST /api/trips/{id}/early-checkin`, `/change-dates`, `/add-transfer` | «Мои поездки» |
| `POST /api/hotels/{id}/inquire` | модалка «Вопрос отельеру» |
| `GET /health` | проверка доступности бэкенда |
| `GET /api/trips?user_id=…` | **нет в спеке** — список бронирований для «Моих поездок» (сейчас из моков) |

